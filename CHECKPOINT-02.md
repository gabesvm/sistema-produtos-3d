# Requisitos do Projeto

Os principais requisitos definidos para o desenvolvimento da aplicação são:

- Cadastro de produtos;
- Visualização da lista de produtos cadastrados;
- Edição de produtos;
- Exclusão de produtos;
- Persistência dos dados utilizando banco de dados SQLite;
- Interface simples e organizada;
- Integração entre front-end e back-end;
- Versionamento do projeto utilizando Git e GitHub.

# Metodologia Utilizada

Para o gerenciamento das atividades do projeto, será utilizada uma metodologia ágil simples baseada na organização das tarefas em etapas de desenvolvimento.

As atividades serão desenvolvidas de forma incremental, permitindo acompanhar a evolução do sistema durante cada checkpoint da disciplina.
