# Checkpoint 03 – Atualização do Desenvolvimento do Projeto

## Projeto: Sistema de Gestão de Produtos 3D

## Descrição

Este documento apresenta a atualização do cronograma e do andamento do desenvolvimento do projeto “Sistema de Gestão de Produtos 3D”, separando as atividades entre front-end e back-end, conforme solicitado pela disciplina.

O objetivo desta etapa é demonstrar a evolução do projeto, identificando as funcionalidades já implementadas e as próximas etapas previstas para o desenvolvimento completo da aplicação.

# Desenvolvimento Front-end

## Funcionalidades já implementadas

- Estrutura inicial do projeto criada no VS Code;
- Organização inicial da documentação do sistema;
- Planejamento das telas da aplicação;
- Definição da interface de cadastro e listagem de produtos;
- Estruturação do repositório no GitHub.

## Funcionalidades previstas

- Tela de cadastro de produtos;
- Tela de listagem dos produtos;
- Tela de edição e exclusão de produtos;
- Estilização visual da aplicação utilizando CSS.

---

# Desenvolvimento Back-end

## Funcionalidades já implementadas

- Definição das tecnologias do back-end;
- Planejamento da estrutura da API;
- Organização inicial do ambiente de desenvolvimento;
- Configuração do versionamento utilizando Git e GitHub.

## Funcionalidades previstas

- Configuração do servidor Node.js;
- Implementação do framework Express.js;
- Criação das rotas da aplicação;
- Integração com banco de dados SQLite;
- Implementação do CRUD completo;
- Persistência dos dados da aplicação.

---

# Banco de Dados

O banco de dados escolhido para o projeto foi o SQLite, devido à sua simplicidade de configuração, leveza e facilidade de integração com aplicações Node.js.

O banco será utilizado para armazenar as informações dos produtos cadastrados na aplicação.

---

# Considerações Finais

Até o momento, o projeto encontra-se em fase de estruturação inicial e organização do ambiente de desenvolvimento.

As próximas etapas envolverão a implementação prática do front-end, do back-end e da integração com o banco de dados, permitindo o funcionamento completo do sistema CRUD.
