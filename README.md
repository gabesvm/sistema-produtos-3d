# Sistema de Gestão de Produtos 3D

## Descrição do Projeto

O projeto consiste no desenvolvimento de uma aplicação web para realizar o gerenciamento de produtos fabricados por impressão 3D. A aplicação permitirá cadastrar, visualizar, editar e excluir produtos, funcionando como um sistema simples de controle de catálogo e estoque.

A ideia surgiu a partir da necessidade de organizar melhor produtos personalizados, como chaveiros, bonecos decorativos, suportes e outros itens produzidos sob encomenda.

## Objetivo da Aplicação

O objetivo da aplicação é permitir que o usuário gerencie produtos de forma prática e organizada, mantendo informações importantes como nome do produto, descrição, categoria, preço, quantidade em estoque e status de disponibilidade.

Com isso, o sistema poderá auxiliar no controle dos produtos cadastrados e facilitar futuras consultas, alterações ou exclusões dos itens registrados.

## Funcionalidades Previstas

- Cadastrar novos produtos;
- Listar produtos cadastrados;
- Editar informações dos produtos;
- Excluir produtos;
- Armazenar os dados em um banco de dados;
- Organizar os produtos por categoria e disponibilidade.

## Tecnologias que Serão Utilizadas

Para o desenvolvimento da aplicação, serão utilizadas as seguintes tecnologias:

- **HTML5**: estrutura das páginas da aplicação;
- **CSS3**: estilização e organização visual da interface;
- **JavaScript**: interatividade e manipulação das informações;
- **Node.js**: ambiente de execução para o back-end;
- **Express.js**: framework para criação das rotas e da API;
- **SQLite**: banco de dados para persistência das informações;
- **Git e GitHub**: versionamento e hospedagem do código-fonte.

## Justificativa das Tecnologias

As tecnologias escolhidas são adequadas para o desenvolvimento de uma aplicação CRUD simples, funcional e de fácil manutenção. O uso de HTML, CSS e JavaScript permite construir a interface da aplicação, enquanto Node.js e Express.js possibilitam a criação do back-end responsável pelas operações do sistema.

O banco de dados SQLite foi escolhido por ser leve, simples de configurar e suficiente para armazenar os dados da aplicação durante o desenvolvimento do projeto.

## Status do Projeto

Projeto finalizado e funcional.

A aplicação conta com um sistema CRUD completo para gerenciamento de produtos fabricados por impressão 3D, permitindo cadastrar, visualizar, editar e excluir produtos com persistência de dados utilizando SQLite.

O sistema possui integração entre front-end e back-end, utilizando Node.js, Express e JavaScript, além de interface web responsiva desenvolvida com HTML e CSS.

Também foram aplicadas boas práticas de organização de código, separação de responsabilidades e integração com API REST.
